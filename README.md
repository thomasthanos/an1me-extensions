# An1me Extensions

Two focused browser extensions for [an1me.to](https://an1me.to), kept together because they improve the same watching flow without pretending to be the same product.

| Extension | What it does | Source |
| --- | --- | --- |
| **An1me.to Tracker** | Automatic progress, resume, library, notifications, AniList integration, stats and optional cloud sync. | [`an1me-tracker/`](an1me-tracker/) |
| **An1me.to Speed Control** | F7/F8 playback-speed controls with remembered speed, volume and mute preferences. | [`an1me-speed-control/`](an1me-speed-control/) |

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` or `edge://extensions`.
3. Enable **Developer mode**.
4. Choose **Load unpacked**.
5. Select the folder of the extension you want:
   - `an1me-tracker`
   - `an1me-speed-control`

Each extension has its own README, manifest, privacy notes, screenshots and assets. They can be installed independently and neither one depends on the other.
